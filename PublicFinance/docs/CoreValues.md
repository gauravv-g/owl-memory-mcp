# Core Values

## 1. Transparency First

**Definition**: Every number, every calculation, every source must be visible and verifiable.

**Behavior**:
- Link every data point to its official source document
- Show methodology for all derived metrics
- Publish data processing pipelines as open source
- Acknowledge uncertainties and data gaps openly
- Version all datasets with clear changelogs

**Anti-Pattern**: Hiding limitations, presenting estimates as facts, obscuring sources.

---

## 2. Accessibility Always

**Definition**: Design for the most constrained user, not the average user.

**Behavior**:
- Test on ₹5,000 Android devices with 1GB RAM
- Optimize for 2G/3G networks, not just broadband
- Support screen readers and voice navigation from day one
- Provide content in user's native language, not just English
- Design for low literacy without being condescending

**Anti-Pattern**: "We'll add accessibility later," assuming high-end devices, English-first design.

---

## 3. Neutrality Non-Negotiable

**Definition**: We present data, not opinions. We enable analysis, not advocacy.

**Behavior**:
- Present multiple perspectives on fiscal policy debates
- Never editorialize budget allocations as "good" or "bad"
- Cite sources across political spectrums equally
- Decline funding that comes with editorial control
- Separate news/updates from analysis clearly

**Anti-Pattern**: Partisan framing, selective data presentation, accepting restricted grants.

---

## 4. Accuracy Over Speed

**Definition**: Wrong data destroys trust permanently. Slow but correct data builds trust gradually.

**Behavior**:
- Implement multi-stage validation before publishing data
- Prefer manual verification over automated scraping for critical datasets
- Clearly mark preliminary vs. finalized data
- Issue corrections prominently when errors are found
- Document confidence levels for all estimates

**Anti-Pattern**: Publishing first and correcting later, hiding corrections, guessing when uncertain.

---

## 5. User Empathy Deep

**Definition**: Understand the real contexts in which users engage with public finance data.

**Behavior**:
- Conduct field research in rural and semi-urban areas quarterly
- Design for intermittent attention (users interrupted by work, family)
- Respect users' time—answer questions quickly, allow deep dives optionally
- Build features that solve actual problems, not hypothetical ones
- Listen to criticism without defensiveness

**Anti-Pattern**: Building for ourselves, assuming user needs, ignoring feedback from non-expert users.

---

## 6. Long-Term Thinking

**Definition**: Build systems that will serve users for decades, not quarters.

**Behavior**:
- Choose boring, proven technologies over trendy ones
- Document decisions thoroughly for future maintainers
- Design for data portability and interoperability
- Invest in technical debt reduction continuously
- Plan for succession, not just launch

**Anti-Pattern**: Quick hacks for demos, undocumented decisions, vendor lock-in, ignoring maintenance costs.

---

## 7. Open Collaboration

**Definition**: We cannot do this alone. Enable others to build on our work.

**Behavior**:
- Publish APIs with comprehensive documentation
- Release tools and libraries as open source
- Welcome contributions from civil society, academia, and government
- Share learnings publicly through blogs and talks
- Partner rather than compete with complementary initiatives

**Anti-Pattern**: Closed APIs, proprietary formats, hostile to forks, knowledge hoarding.

---

## 8. Humility in Complexity

**Definition**: Public finance is inherently complex. Simplify without distorting.

**Behavior**:
- Admit when something cannot be simplified further
- Provide progressive disclosure: simple summary → detailed breakdown → raw data
- Explain trade-offs in simplification choices
- Consult domain experts before designing abstractions
- Test comprehension with real users, not just colleagues

**Anti-Pattern**: Oversimplifying to the point of misinformation, hiding complexity without acknowledgment.

---

*These Core Values operationalize the Vision and Mission. Hiring, performance reviews, and product decisions should reference these values explicitly.*
